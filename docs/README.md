# Supplementary documentation

Extended material that supplements the manuscript. The files are plain Markdown; the machine-readable sources are in `results/`, `prompts/`, and `scenarios/`.

| File | Content |
|---|---|
| `prompts.md` | System prompts of the J2, J3, J4, and JAG agents (original), the neutral JAG prompt, and the user-message templates |
| `worked_example_S5.md` | Complete record of one run (scenario S5, VWA-Full, Llama 3.1 8B, temperature 0, repeat 1): all agent inputs and outputs and the IACB audit log |
| `scenarios.md` | The 14 scenarios with Vibe text, structured context, author-assigned labels, the principle tested, and the author's notes on the borderline scenarios |
| `extended_results.md` | Per-scenario outcomes, robustness table, label-sensitivity table, threshold sweep, latency and concurrency details, and the error analysis |

All labels are assigned by the author; "agreement" is agreement with these labels and not an independent measure of legal correctness. The code is a research prototype for a simulation study and must not be used to support real operational or targeting decisions.
